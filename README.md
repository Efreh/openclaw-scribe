# openclaw-scribe

Браузерное расширение и нативный плагин OpenClaw для записи и расшифровки
аудио. Язык проекта — TypeScript; отдельный сервер не предусматривается.
Стенограммы передаются в штатную систему встреч OpenClaw.

Сейчас в репозитории создана только структура: реализации, зависимостей,
сборки и работающего CI пока нет.

## Структура репозитория

```text
.
├── .github/
│   └── workflows/       # будущие проверки GitHub Actions
├── .gitignore           # локальные файлы и результаты сборки
├── AGENTS.md            # правила работы с этим репозиторием
├── LICENSE
├── README.md
└── src/                 # корень проекта и будущих настроек TypeScript/сборки
    ├── extension/       # расширение браузера: захват аудио и интерфейс
    ├── plugin/          # нативный плагин OpenClaw
    ├── shared/          # общий протокол и типы расширения и плагина
    └── spec/
        ├── unit/        # изолированные проверки компонентов
        ├── integration/ # проверки взаимодействия компонентов
        └── support/     # общие вспомогательные средства тестов
```

Пустые каталоги сохранены в Git файлами `.gitkeep`; при добавлении реальных
файлов соответствующие `.gitkeep` следует убрать.
