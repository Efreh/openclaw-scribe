# Проверка 0.4.0

Изменение: основной ASR при диаризации выполняется только после остановки.
Галочка «Показывать текст» включает независимое одноразовое демо обеих
дорожек; его результат никогда не сохраняется и не используется для финала.
Микрофон временно записывается отдельно и распознаётся после остановки,
независимо от демо. Без диаризации сохраняется прежний однократный live-ASR.

Проверки:

- TypeScript и 21 unit/integration-тест: ноль вызовов ASR до остановки
  при выключенном демо; отдельные финальные вызовы для обеих дорожек
  при любом состоянии галочки; отсутствие демо-текста на диске и в native
  архиве; отсутствие подстановки демо при ошибке финала; приватные WAV
  остаются для восстановления; переключение демо и игнорирование позднего
  ответа; медленное и ошибочное демо не блокирует ACK основного аудио.
- Запись только микрофона: сохранение временного смещения, пропуск тишины,
  отсутствие вызова диаризатора без аудио вкладки; ограничение размера
  временного файла и четырёхчасового интервала для обеих дорожек.
- Chromium MV3: настройки и безопасный вывод; настоящий tabCapture и
  синтетический микрофон; закрытие popup и смена вкладки; два режима старта
  демо; переключения выключено → включено → выключено во время записи;
  основной финальный ASR обеих дорожек после Stop.

- Установка готового TGZ в отдельный OpenClaw 2026.10.7: команда pair
  выдаёт постоянный полный токен без записи в журнал, повторный вызов его
  не меняет.
- Аппаратная проверка готового TGZ: GigaAM 600M / PyTorch / CUDA + Nemotron,
  публичный двухголосный 30-секундный пример pyannote в обеих входных
  дорожках; демо выключено, 6 ACK до остановки и 0 живых строк. После
  остановки — 14 итоговых реплик, микрофон, оба голоса и пересечение,
  native стенограмма и итог. Предупреждений и подстановки демо нет.

Для управления демо нужны **и плагин, и расширение 0.4.0**. Старый клиент
с протоколом v1 остаётся совместимым, но не передаёт состояние галочки:
у него демо по умолчанию включено. Новый клиент явно отклоняет старый
плагин при запросе диаризации, чтобы не имитировать оптимизацию.
Токен подключения и настройки моделей при обновлении не меняются.

Методика аппаратной проверки установленного TGZ в отдельном профиле:

~~~sh
npm run test:native -- --audio /path/to/two-speakers.wav --language en --duration 30 --diarization --microphone --asr-config /path/to/asr.json
~~~

Без `--preview` в режиме диаризации демо выключено. `--microphone` подаёт
публичный тестовый звук также во вторую дорожку, без записи реального микрофона.
Проверяются ACK до остановки, отсутствие живых текстовых ответов, результат
по участникам, финальный микрофон и native стенограмма/итог. Изолированный
тест не меняет конфигурацию рабочего Gateway. Аудио, вывод и локальные пути
проверок не входят в Git и архивы.
