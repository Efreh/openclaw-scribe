# План: сохранение аудио и открытие папки записи

Статус: реализовано в 0.5.0.
Документ фиксирует согласованное поведение сохранения аудио.
Существующее поведение описано отдельно в [audio-flow.md](audio-flow.md).

## Управление

Три независимых переключателя:

- «Разделить собеседников после записи» — диаризация звука вкладки.
- «Сохранять аудиозапись» — оставлять полные аудиофайлы после успешной обработки.
- «Показывать текст» — отображение основного текста в потоковом режиме либо
  независимое эфемерное демо ASR в режиме полной записи.

Кнопка «Открыть папку записи» открывает каталог конкретной сохранённой записи.
Диаризацию и сохранение аудио выбирают до начала записи; во время записи
их не меняют. Превью можно переключать во время записи.

## Дорожки

Звук вкладки и микрофона не смешивается:

- `tab.wav` — полная захваченная дорожка вкладки.
- `mic.wav` — полная захваченная дорожка микрофона, только если он включён.

Под сохранением понимается сохранение файлов после обработки, а не только
их временное существование до распознавания. Отдельных чистых аудиодорожек
каждого говорящего нет: диаризация находит интервалы голосов внутри вкладки
и подписывает текст, но не разделяет смешанный звук.

## Матрица режимов

| Диаризация | Сохранять аудио | Основной ASR | Аудио после успеха |
| --- | --- | --- | --- |
| Выкл. | Выкл. | Во время записи, порциями | Полная запись не накапливается |
| Выкл. | Вкл. | После остановки | Оставить |
| Вкл. | Выкл. | После остановки; вкладка с диаризацией | Удалить временные файлы |
| Вкл. | Вкл. | После остановки; вкладка с диаризацией | Оставить |

Сохранение аудио само по себе не включает диаризацию.

### Без диаризации и без сохранения

Сохранить существующий потоковый режим:

`вкладка / микрофон → порции аудио → основной ASR → сохранение текста`

Речь распознаётся во время записи один раз. «Показывать текст» только
показывает или скрывает основной текст; отдельное демо не запускается.
При остановке досылается оставшийся фрагмент. Повторного ASR нет.
Полная аудиозапись не накапливается; это не исключает временный WAV
отдельного запроса ASR.

### Без диаризации, с сохранением

Во время записи непрерывно накапливать обе включённые дорожки в файлах.
Основной ASR в это время не выполнять. При включённом превью независимо
обрабатывать копии фрагментов только для интерфейса.

После остановки:

`сохранённые дорожки → основной ASR без диаризации → объединение по времени → сохранение стенограммы`

Использовать метки «Вкладка» и «Микрофон». Полные аудиофайлы оставить.
Файл может подаваться модели допустимыми порциями: это итоговый проход
после остановки, а не live-ASR. Демо-текст не переиспользовать.

### С диаризацией, без сохранения

Сохранить существующий принцип: обе дорожки во время записи накапливаются
во временных файлах, основной ASR ждёт остановки.

После остановки:

- Вкладка: полный WAV → Nemotron → интервалы говорящих → основной ASR.
- Микрофон: сохранённый WAV → отдельный основной ASR без диаризации.
- Объединить реплики по времени и сохранить финальную стенограмму.
- После успешного сохранения удалить временное аудио.

### С диаризацией и сохранением

Основной путь и демо полностью совпадают с предыдущим режимом.
Разница только в хранении: после успеха аудиофайлы оставить.
Существующую логику независимого демо при диаризации не переделывать.

## Независимое эфемерное превью

Режим полной записи действует, если включена диаризация ИЛИ сохранение аудио.
В нём основная запись в файлы продолжается независимо от превью:

- Превью выключено: новые live-запросы ASR не выполнять.
- Превью включено: дополнительно отправлять копии поступающих фрагментов
  в ASR только ради непосредственного отображения текста.

Демо не должно создавать второй захват источника. Его результат хранится
только во временном состоянии интерфейса, не записывается в текстовый архив,
не используется для финала, включая микрофон, и не служит резервным
результатом при ошибке основной обработки.

Переключение действует на новые демо-запросы. Уже начатый запрос может
завершиться, но его поздний ответ после выключения не показывается.
Ошибки или медленная очередь демо не должны останавливать сохранение аудио.
Закрытие popup само по себе не выключает запись и не меняет галочку.

Без превью каждый обрабатываемый участок проходит основной ASR один раз.
При включённом превью дополнительная работа выполняется намеренно ради
просмотра; она не подменяет основной итоговый проход.

## Хранение и открытие папки

Для каждой сохраняемой записи использовать отдельную постоянную папку
с её полными дорожками, а не оставлять их неопределённо во временном work.

После завершения записи кнопка «Открыть папку записи» должна открывать
каталог именно этой записи, а не общий корень всех записей. При отсутствии
сохранённых аудиофайлов кнопка недоступна.

Открывать папку на компьютере Gateway, где физически находятся файлы.
Не выдавать это за открытие папки на другом компьютере браузера.

## Ошибки и финальный результат

Если используется полная запись и итоговая обработка либо сохранение
стенограммы завершились ошибкой, не удалять накопленное аудио; сохранить
его для восстановления и показать ошибку. Демо не выдавать за финал.
Это правило не обещает восстановление полной записи в потоковом режиме,
где полный файл не накапливался.

В штатный архив стенограмм передавать только основной результат.
В режимах полной записи после обработки заменять демо в виджете итоговой
стенограммой, если отображение текста включено. При выключенном отображении
итоговая стенограмма всё равно должна сохраняться.

## Сводные правила

- Полная запись: `diarization || saveAudio`.
- Основной ASR: после остановки при полной записи, иначе потоковый.
- Дополнительный демо-ASR: только при полной записи и включённом превью.
- Оставлять полное аудио после успеха: только при включённом сохранении.
- Сохранённое аудио при ошибке полной обработки не удалять.

## Расположение файлов (0.5.0)

После успеха с сохранением: `<stateDir>/scribe/recordings/recording-*`.
При ошибке полной обработки: `<stateDir>/scribe/work/recording-*`.
Права на каталоги — `0700`, на WAV и метаданные — `0600`.
Кнопка в виджете обращается к локальному плагину с токеном подключения;
передаёт только ID записи, не произвольный путь. Удалённые файлы, подмена
папки символической ссылкой и ошибочное открытие показываются явно.

Виджет использует компоновку «Пульт», светлую и тёмную палитры в духе
IntelliJ IDEA; выбор темы сохраняется локально и не влияет на запись.
